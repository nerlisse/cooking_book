# Кулинарная книга

**Кулинарная книга** — это полноценное веб-приложение для ведения книги рецептов.  
Пользователи могут создавать, редактировать и сохранять свои рецепты, добавлять фотографии, делиться блюдами с другими и открывать новые кулинарные идеи.

Проект написан на Kotlin.

---

## ✨ Основные возможности

- Добавление, редактирование и удаление рецептов
- Управление шагами приготовления и ингредиентами
- Загрузка и просмотр изображений блюд
- Поиск и фильтрация по названию
- REST API для интеграции с другими сервисами

### Backend

## Быстрый старт

### Требования
- Docker и Docker Compose
- JDK 17+

### Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/nerlisse/cooking_book.git
   cd cooking_book
    ```

2. Создайте файл .env и укажите настройки:
    ```bash
    DB_USER=postgres
    DB_PASSWORD=postgres
    DB_NAME=cookingbook
    ```


3. Запустите приложение:
   ```bash
   docker compose up --build
   ```
